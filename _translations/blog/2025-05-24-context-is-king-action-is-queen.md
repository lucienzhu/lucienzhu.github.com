Agent （智能体）作为 2025 年 AI 的关键词，已经热到不能再热了。

不同于上一代硬核 AI，融资额大量投入在基础模型及解决方案研发上；这一轮 AI 的创业者是以产品为主，在 inference 有利润空间后，验证 PMF 后，快速起量增长，成就了第一波成功的商业化浪潮。

正如红杉近日的讨论，MaaS/SaaS，不够性感。商业模式应该从订阅制，向更激进的按结果付费突破。在更高频的价值交付中，争取 AI 应得的分成。

连一向保守的欧洲创业圈，在 Agent 方向 2025 年前六周都获得近 500M 的融资，实属罕见。

AI 在 Agent 浪潮下，从元年快速迈进到下半场。

## AI 价值多少？你成功的一半。

通俗来说，Agent 在做的事，就是替换人的工作，和环境进行交互。

比如上网订一张机票，环境就是浏览器。

比如写一个网站，环境就是代码编辑器。

比如控制一台电脑，环境就是命令行。

{% include article-image.html src="/img/blog/context-is-king-action-is-queen/human-agent-environment.png" alt="人、智能体与环境的交互关系" width="1348" height="1198" %}

人干活时，任务越复杂，越容易拖延；任务越简单，越容易分神。总之活儿到身上，立刻开始是不可能的。要不也不会有什么 GTD，番茄钟之类的效率神器这么畅销了。

AI 出现后，这一切发生了翻天覆地的变化：

- ChatGPT 降低了问答的门槛，提供了比搜索引擎更自然的交互体验；
- DeepSeek 提供了清晰的思路分析，让人在决策时更信赖 AI 的建议；
- 以 Manus 为代表的智能代理，通过结合 browser use 和 terminal use，覆盖了更广泛的使用场景。

AI 解决了人们工作中的冷启动问题，打开了每个人解决问题的可能性。这样好的开始，价值难道不是成功的一半？

## Context is King

这一波 Agent 应用公司越来越多，大有当年百团大战的热闹程度。

历史不会重复，但会押韵。

相比于PC互联网和移动互联网时代，AI 时代对用户的争夺，不单单是抢入口这么简单，Tiktok 到达 1 亿月活用了 9 个月，ChatGPT 则不到 2 个月。打造爆款已经不是难题。

{% include article-image.html src="/img/blog/context-is-king-action-is-queen/product-growth.png" alt="不同产品达到百万用户所需时间，原文配图" width="1214" height="498" %}

更重要的是 context。对用户摸的足够准，不让用户思考，以最少的输入换取最大价值的输出，解决实际的问题，是这一轮 Agent 企业制胜的关键。

从 MOAT 角度来说，context is King. 

像 OpenAI 这样独有 500M 月活高质量真人用户 context 的公司，短时间内很难有第二家。换句话说，和 AI 产品交互的越久，离开的成本就越高，概率就越小。

尤其是套壳产品，在验证 PMF 后，如何有效积累 context，无论是用户 knowledge base 还是 feedbacks，是产品设计的和用户成功的关键。

## Action is Queen

有了大模型，现在的 AI 产品出手时就非常 powerful，但光用到这一个杠杆，还是不够的。

纵观 AI 发展的里程碑和明星产品，我们可以看到：

- AlphaGo 在围棋领域取得超人成就，让世界首次认识到 AI 的真正价值；
- GAME AGI 在 Minecraft 中持续迭代，现已稳定找到钻石，成为多模态模型的标杆；
- Cursor 在 VS Code 基础上，打造了一款高效的编程助手；
- Manus 将浏览器操作和终端使用完美结合，进入扩大了个人的能力栈；
- Lovable 基于成熟的 React 技术栈，创造出令人惊艳的个人网站；
- Lovart 借助 Comfy UI 强大的工作流，实现惊艳的创作效果。

如何定义 Agent 的 Action Space，直接影响到这一轮 AI 产品的天花板。

在 vertical 中，对行业的理解和工具的有效利用，定义出 Agent 的高质量 Action，决定了你的 Agent 的交付成果。

Action is Queen。好的 action 定义就好比联姻一样，直接能撬动一块巨大的市场。

## 前进三

巴菲特在最后一次股东大会上感慨：我们应当感谢这个时代。

人工智能历经数次浪潮，不再是实验室的玩具，迈入了人类社会，直接影响我们每个人的生活。

蒸汽时代，钢铁巨兽在齿轮与连杆间苏醒，掀开工业文明的帷幕。

电气时代，电流化作魔法，让控制系统自我运转，点亮城市与工厂。

信息时代，比特织成全球神经，连接亿万人心智，重塑沟通与组织形态。

智能时代，深度神经网络跨越专业鸿沟，赋予每个人前所未有的能力。

我们不仅在驱动机器，更在与之共生。

一步步向机器文明迈进，驱动它，成为它。
