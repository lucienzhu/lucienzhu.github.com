我们与伦敦的联合创始人共同研发 SuperIntern，一款面向 Discord、Slack 的群聊 AI 智能体，利用共享上下文答疑、执行任务，直接在聊天中解决办公和营销问题。

## 多模型平台

工作涵盖 Llama 3 对话、图像生成和 TTS 多模型平台，将模型服务接入可交互的产品体验。

## Agent 工程化

参与 Agent API、工具接入，以及围绕 Trigger、Jobs、Agent Task 组织的任务工作流研发。通过部署、版本管理与日志观测，支持模型服务与任务执行流程的迭代。

## 模型与 Agent 对齐

团队对 Stable Diffusion 进行有监督微调（SFT），并应用直接偏好优化（DPO）开展模型对齐。

以群聊作为共享上下文和人类反馈的场景，探索如何让 Agent 行为与群体需求、偏好相匹配。关注人机共同对齐（human–AI co-alignment）：人在与 Agent 持续互动中，双方如何相互适应。
