研发面向群聊的 Agent 产品，利用共享上下文在 Discord、Slack 中答疑并执行任务。与群体需求和偏好的 Alignment，是这条产品线的重要方向。

## 从 NeuroMesh 到 Super Intern

项目早期以 NeuroMesh 推进，后更名为 Super Intern。早期工作涵盖 Llama 3 对话、图像生成和 TTS 多模型平台，将模型服务接入可交互的产品体验。

## Agent 工程化

参与 Agent API、工具接入，以及围绕 Trigger、Jobs、Agent Task 组织的任务工作流研发。通过部署、版本管理与日志观测，支持模型服务与任务执行流程的迭代。

## 模型与 Agent 对齐

对 Stable Diffusion 进行有监督微调（SFT），并应用直接偏好优化（DPO）开展模型对齐。

以群聊作为共享上下文和人类反馈的场景，探索如何让 Agent 行为与群体需求、偏好相匹配。关注人机共同对齐（human–AI co-alignment）：人在与 Agent 持续互动中，双方如何相互适应。
